      About this hub

      What this software is and how it was made.

      ⚙

      What is this?

      Overview

      One single software that puts every project I have ever written into a single place. Instead of hunting through folders, everything is scanned, sorted and shown here.

      PythonFlask HTMLCSS JavaScriptSQLite
      💾

      How it works

      Architecture

      build_catalog.py walks my folders and writes data/projects.json. app.py is the Flask backend that serves that data, reads source files and powers the live wallet. The frontend renders it all.

      ⚡

      Three ways to run

      Flexible

      Start app.py for the full experience with a live database. Run python build_static.py to publish the entire thing as a plain website on GitHub Pages. Or just open templates/index.html - it still works using the bundled catalogue, with the wallet in offline demo mode.

      🔄

      Always in sync

      Fresh

      Finished something new? Run python build_catalog.py (or press Rescan below) and it appears here immediately - no manual editing.

      🔒 Privacy and safety
      🔒

      Nothing private is published

      Privacy

      The catalogue only ever stores relative paths. No absolute path, no user name and no email address is written into data/projects.json or sent to the browser.

      🔑

      Jailed file reader

      Security

      The code browser refuses .. traversal, drive letters, UNC paths and null bytes, and resolves symlinks before checking the target is still inside the workspace.

      🔢

      Binds to localhost

      Network

      By default the server listens on 127.0.0.1 only, so it is not reachable from other machines. To publish it, set HUB_MODE=public (which also switches off the file reader and rescan) and HOST=0.0.0.0 so the platform can reach it.

      ⚿

      Hardened headers

      Defense in depth

      Every response carries a Content-Security-Policy, nosniff, X-Frame-Options DENY, no-referrer and a restrictive permissions policy. Mutating endpoints are rate limited.

      ⚙ Reset and reconfigure

      The name shown in the title bar comes from OWNER_NAME and APP_TITLE in your .env file. Copy .env.example to .env to change it - .env is git-ignored so it stays private.
